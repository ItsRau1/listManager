═══════════════════════════════════════════════════════════════

1. ✅ EXCLUIR ITENS
   → Como: Pressione e segure (long press) um item
   → Confirmação: Diálogo "Excluir Item?"
   → Resultado: Item removido permanentemente

2. ✅ EXCLUIR LISTAS
   → Como: Pressione e segure (long press) uma lista
   → Confirmação: Diálogo "Excluir Lista?" + aviso
   → Resultado: Lista e todos os itens removidos

═══════════════════════════════════════════════════════════════
  🎯 COMO USAR
═══════════════════════════════════════════════════════════════

EXCLUIR UM ITEM:
1. Abra uma lista
2. Pressione e segure o item desejado
3. Confirme "Excluir" no diálogo
4. Item é removido!

EXCLUIR UMA LISTA:
1. Na tela principal
2. Pressione e segure a lista desejada
3. Confirme "Excluir" no diálogo (atenção: todos os itens serão perdidos!)
4. Lista é removida!
